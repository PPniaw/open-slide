Live interaction is now a publish-time switch: published decks show a corner QR code (Q toggles it), the presenter's spotlighted question as a caption and rising reactions, and the workspace gets a Live panel to run the room. No workshop code or admin link anymore. Unpublishing or switching live off closes the room on the service, and admin keys are stored per user in ~/.slidez instead of inside the project.
