# 現場互動

## 最簡單的做法：不用改簡報

現場互動是**發布時的開關**，不是簡報內容。使用者說「我要讓觀眾發問／回饋」時，先告訴他：

1. 按工具列的「發布」，勾選「**開啟現場互動（發問、回饋）**」，再發布上線。
2. 播放時簡報**右下角**會自動出現 QR code，觀眾用手機掃了就能發問、按讚、評分、送表情、留心得。播放中按 `Q` 可以隱藏或顯示 QR code。
3. 工作台工具列會多一個「**互動**」按鈕：講者在這裡看問題、按「上螢幕」（問題會以字幕出現在簡報下方）、標記已回答、看回饋、匯出 CSV、暫停發問、切換匿名或具名。

這種情況**不需要寫任何程式**，也不要為了互動去改簡報。沒有工作坊代碼、沒有另外的管理網址，管理只在工作台裡做。

## 想自訂版面時：互動區塊（進階）

只有使用者明確想要「某一頁放大 QR code」「整頁顯示問題牆」「結尾頁顯示評分」時，才用 `@open-slide/core/live` 的區塊。在簡報裡做互動**只能用這三個元件**，不要自己寫 WebSocket、表單或輪詢，也不要加套件。

```tsx
import { LiveFeedback, LiveJoin, LiveQA } from '@open-slide/core/live';
```

| 元件 | 簡報上顯示什麼 | 常用 props |
|---|---|---|
| `<LiveJoin />` | 大的 QR code、短網址、在線人數 | `label`、`size`（QR 邊長，預設 320）、`showCount` |
| `<LiveQA />` | 講者按過「上螢幕」的問題，依讚數排序 | `title`（預設「現場提問」）、`limit`（預設 4） |
| `<LiveFeedback />` | 平均評分、表情累計，表情會往上飄 | `title`（預設「即時反饋」）、`show`（`['rating', 'reactions']` 的子集合） |

三個元件都接受 `className` 和 `style`，尺寸照 1920×1080 畫布設計，字體與強調色跟著主題的 `--osd-font-body`、`--osd-accent`。

```tsx
const QA: Page = () => (
  <div style={{ display: 'flex', gap: 96, padding: 120, height: '100%' }}>
    <LiveJoin size={260} label="掃碼發問，也可以幫別人的問題按讚" />
    <LiveQA style={{ flex: 1 }} limit={4} />
  </div>
);
```

## 規則

- **用了互動區塊，發布時互動就一定是開的**，發布視窗的開關會鎖定勾選。
- **發布後才會連線。** 在工作台裡，沒開互動的簡報，區塊會顯示虛線框預留位置，這是正常的，不要試圖「修好」它。
- **簡報上只會出現講者挑選的問題。** 觀眾手機上看得到全部問題（除非講者改成「我公開後才出現」），簡報只顯示講者按「上螢幕」的。
- **心得只有講者看得到**，不會出現在簡報上。
- **縮圖、總覽和 PPTX/PDF 匯出不會連線**，只畫靜態內容。
- **免費版每場有人數上限**（預設 30 人）。滿了之後新的手機會看到「已滿」。
- 投票、測驗、抽獎還沒有。使用者要的話，說明目前只支援發問和回饋，不要自己實作。
